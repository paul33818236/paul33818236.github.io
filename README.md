# paul33818236.github.io

This repository contains a personal webpage for Paul, a student at Yuan Ze University.
The website introduces Paul, highlights learning interests, and provides a simple place
to grow future portfolio content.

## Techniques Used

- HTML5 is used to structure the personal webpage content.
- CSS3 is used for layout, colors, spacing, typography, and responsive design.
- CSS Grid and Flexbox are used to organize sections across desktop and mobile screens.
- Media queries are used to make the page adapt to smaller devices.
- A single standalone `Index.html` file keeps the site simple to publish with GitHub Pages.

## Main File

- `Index.html`: The personal webpage source code.
